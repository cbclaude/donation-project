## Features
- Password-protected login
- 24 products across 9 categories
- Products & Brands mega-menu dropdowns (certifiedbrands.com category tree)
- Animated brand logo ticker (Shop by Brand)
- Full product detail pages with images, descriptions & features
- Cart, checkout & order confirmation flow
- Live search with instant results
- Shop filters: brand, category, price, sale, new arrivals
- Help pages: FAQ, Shipping, Returns, Warranty, Contact, Our Mission
- Proceeds messaging throughout supporting WWP veterans

## Deployment
Drop the folder on any static host (GitHub Pages, Netlify, Vercel, S3, etc.) — no server or build step required.
